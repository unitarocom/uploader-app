Uploader App

A personal tool for managing the owner's own YouTube channels.

What it does

Uploader App is a small script that runs on its owner's own computer.

It uses the YouTube Data API and the YouTube Analytics API to upload videos to channels the owner manages, set thumbnails, schedule or change the privacy of those videos, and read view counts and other statistics of those channels.

It is not offered to anyone else and has no public sign-up.

This app uses YouTube API Services.

日本語

Uploader App は、持ち主が自分の PC で動かす個人用のツールです。

YouTube Data API と YouTube Analytics API を使い、持ち主が管理する YouTube チャンネルへの動画のアップロード、サムネイルの設定、公開予約や公開範囲の変更、再生数などの統計の読み取りを行います。

持ち主以外には提供しておらず、登録の受付もありません。

このアプリは YouTube API サービスを使用しています。
