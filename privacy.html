Privacy Policy

Uploader App · Last updated: November 15, 2026

Who uses this app

Uploader App is a personal tool used only by its owner, on the owner's own computer, for YouTube channels the owner manages.

It is not offered to the public.

Data the app accesses

With the owner's permission through Google sign-in, the app accesses:

  • basic information about the owner's YouTube channels;
  • the owner's videos and their titles, descriptions, tags, thumbnails, privacy and schedule settings;
  • statistics of the owner's channels and videos from YouTube Analytics, such as views, watch time and traffic sources.

How the data is used

The data is used only to upload and manage the owner's own videos and to keep a record of the owner's own channel statistics.

It is not used for advertising, it is not sold, and it is not shared with any third party.

Uploader App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Where the data is stored

Sign-in tokens and the recorded statistics are stored only on the owner's computer.

The app sends requests only to Google's APIs and does not send data to any other server.

This website does not use cookies, analytics or tracking.

Revoking access and deleting data

Access can be revoked at any time on the Google Account permissions page.

Deleting the token files on the owner's computer removes all stored sign-in data.

YouTube and Google

This app uses YouTube API Services.

Use of YouTube through this app is subject to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Changes and contact

If this policy changes, the new version will be posted on this page with a new date.

Questions can be sent through this website's GitHub repository issues.

日本語

使う人

Uploader App は、持ち主だけが自分の PC で、自分が管理する YouTube チャンネルのために使う個人用のツールです。

一般には提供していません。

扱うデータ

Google のログインで持ち主が許可した範囲で、チャンネルの基本情報、動画と動画の設定（タイトル、説明、タグ、サムネイル、公開範囲、予約）、YouTube Analytics の統計（再生数、視聴時間、流入元など）を扱います。

使い方

持ち主自身の動画のアップロードと管理、持ち主自身のチャンネルの統計の記録にだけ使います。

広告には使わず、販売せず、第三者に渡しません。

Google API から受け取った情報の利用と移転は、制限付き使用の要件を含め、Google API サービスのユーザーデータに関するポリシーに従います。

保存場所

ログインのトークンと記録した統計は、持ち主の PC にだけ保存します。

通信先は Google の API だけで、ほかのサーバーにはデータを送りません。

このウェブサイトは、Cookie・アクセス解析・トラッキングを使っていません。

取り消しと削除

アクセスの許可は、Google アカウントの「サードパーティ製のアプリとサービス」のページからいつでも取り消せます。

PC のトークンのファイルを消すと、保存したログイン情報はすべて消えます。

YouTube と Google

このアプリは YouTube API サービスを使用しています。

YouTube の利用には YouTube 利用規約が、Google のデータの扱いには Google プライバシー ポリシーが適用されます。
